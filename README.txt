ItemWorth - mostra o valor de venda do item ao passar o mouse (tooltip).

Precisa de: Paper 1.21+, ProtocolLib, SellPlugin (a versão nova, com getUnitPrice).
Compilar: mvn clean package -> target/ItemWorth-1.0.jar -> plugins/

/valoritem          liga/desliga só para você
/valoritem reload   recarrega os textos (itemworth.admin)
